В журнале обновления в 09:14 новый процесс 87651 штатно завершился через 0,131 с. Такой ранний выход соответствует защите от второго экземпляра до запуска основной части приложения. Исторический журнал не содержит PID найденного ею второго экземпляра, поэтому конкретный устаревший peer однозначно не установлен. В старой реализации приложение безусловно завершалось после попытки активировать любой другой процесс. Теперь завершившиеся записи пропускаются, проверяется наличие живого PID и повторно проверяется гонка при неуспешной активации; живой экземпляр по-прежнему защищает от двух обработчиков ввода. Добавлены сообщения о старте/передаче живому процессу.

Регрессионные проверки ловят старую логику (4 теста/5 нарушений), исправленная версия проходит 35/35 Core tests. HistoryChecks и проверка выпуска (29/29) проходят.
