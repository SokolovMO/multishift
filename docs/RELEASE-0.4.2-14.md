# Выпуск MultiShift 0.4.2 (14) и MultiSwitcher 0.4.5 (79)

Дата: 16 ноября 2026. Обновления опубликованы по запросу владельца.

## Изменения

- В обоих приложениях есть общий выключатель системных уведомлений. Использован нативный SwiftUI switch малого размера, в правой части строки.
- В MultiShift тест использует текущий язык приложения, с русским текстом «уведомления готовы».
- Завершённую карточку MultiShift можно закрыть или отключить её показ. Файлы и история сохраняются. Кнопки открытия и закрытия центрированы по вертикали.
- DMG обоих продуктов получили общее монохромное оформление и увеличенное окно 760×640, чтобы панели Finder не обрезали композицию. Перетаскивание остаётся штатной операцией Finder.
- У иконок общий нативный исходник подложки. RGB 251/251/251; фон, прозрачность, контур и тень проверены побайтно вне области фирменных знаков. Стандартная папка «Программы» и системные элементы Finder сохраняют оформление macOS.

## Проверки и границы

- macOS 27.2.1, SDK 27.2. MultiShift: macOS 14+, MultiSwitcher: macOS 15+, arm64.
- Swift Core: 31/31; Python: 37/37 (включая 29 проверок выпуска); HistoryChecks, SecureInputChecks и 12 проверок тумблера прошли.
- ICNS, подписи ZIP/DMG/appcast, монтирование установщиков и selftest проверены. Оба маршрута `/download` указывают на конечные builds 14/79. Существующий nginx не изменялся и не перезапускался; previous сохранён.
- Настоящие окна настроек и DMG наблюдались в предыдущих кандидатах. Последние изменения центрирования и иконки проверены сборкой и сравнением ресурсов; новый системный тестовый баннер визуально не наблюдался.
- Пользовательские приложения не переустанавливались и не перезапускались. Проверка Sparkle использует отдельный bundle ID и не запускает установщик.
- Для native-only builds 13/14 переиспользован неизменённый проверенный Python-движок 0.4.2 из build 12. Нативная часть компилировалась и подписывалась заново.
- Подпись MultiShift локальная ad-hoc, MultiSwitcher сохраняет прежний локальный сертификат. Нотарификации Apple нет.

Релизные архивы исходников опубликованы штатно вместе с приложениями. Отдельный push в GitHub первоначально отклонила автоматическая проверка. 16 ноября владелец явно разрешил публикацию исходников и обновление подписей версий на сайте.
